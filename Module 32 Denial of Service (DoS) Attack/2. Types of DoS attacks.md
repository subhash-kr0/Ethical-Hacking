# Types of Denial of Service (DoS) Attacks

Denial of Service (DoS) attacks come in various forms, each targeting different aspects of a network, server, or application. Below are the most common types of DoS attacks:

## 1. **Flooding Attacks**
Flooding attacks overwhelm a target system with excessive traffic, consuming its resources like bandwidth, CPU, or memory, which can make the system unavailable to legitimate users.

### Types of Flooding Attacks:
- **UDP Flood:**
  The attacker sends a large number of User Datagram Protocol (UDP) packets to random ports on the target system. This forces the system to process and respond to each packet, depleting resources and causing a denial of service.

- **ICMP Flood (Ping of Death):**
  The attacker sends a large number of Internet Control Message Protocol (ICMP) Echo Request (ping) packets to the target, consuming the target's bandwidth and resources. The "Ping of Death" is a specific form where the packet size exceeds the maximum allowable size for an ICMP packet.

- **SYN Flood:**
  In this attack, the attacker sends a large number of SYN requests to a target system, pretending to initiate a TCP handshake. However, the attacker does not respond to the SYN-ACK reply, leaving the target server with open connections, causing it to run out of resources.

- **HTTP Flood:**
  The attacker sends an overwhelming amount of HTTP requests to a web server, consuming bandwidth and server resources. Unlike traditional flooding attacks, HTTP Floods often mimic legitimate user requests, making them harder to detect.

## 2. **Application Layer Attacks**
Application layer attacks target the software or services at the application layer, aiming to disrupt the functioning of a web server or application. These attacks are harder to detect because they often appear as legitimate traffic.

### Examples:
- **Slowloris:**
  Slowloris works by keeping many connections to the target web server open and holding them open for as long as possible. The attacker sends partial HTTP requests and never completes them, which prevents the server from closing connections, consuming its resources.

- **HTTP Flood:**
  The attacker floods a web application with a high volume of HTTP requests, overwhelming the web server's ability to process them. Unlike simple flooding attacks, this attack is specifically designed to target the application layer.

- **DNS Query Flood:**
  The attacker sends a large number of DNS queries to a target DNS server, consuming resources and preventing legitimate queries from being processed.

## 3. **Distributed Denial of Service (DDoS) Attacks**
DDoS attacks are a more advanced and large-scale form of DoS attacks, involving multiple compromised machines (often part of a botnet) to flood the target system with traffic. This makes it harder to mitigate as the traffic originates from many sources.

### Examples:
- **Botnet Attacks:**
  The attacker controls a network of infected devices (botnet) and uses them to launch a large-scale, coordinated attack on the target. This increases the attack's intensity and makes it difficult to block.

- **Amplification Attacks (e.g., DNS Amplification, NTP Amplification):**
  The attacker exploits vulnerable servers (e.g., DNS or NTP servers) to send a small request to the target, which then causes the server to send a much larger reply to the victim. The volume of data being sent is amplified, overwhelming the target system.

## 4. **Resource Exhaustion Attacks**
These attacks aim to exhaust critical resources of a system such as CPU, memory, database connections, or file descriptors, which results in service disruptions or crashes.

### Examples:
- **Memory Exhaustion:**
  The attacker sends requests that cause the server to allocate excessive memory or result in memory leaks. Over time, this exhausts system memory, causing the server to crash or slow down.

- **CPU Exhaustion:**
  The attacker sends complex or resource-intensive requests that consume excessive CPU power, causing the target server to become unresponsive.

- **Database Exhaustion:**
  The attacker sends queries that consume excessive database connections or force inefficient queries, causing the database server to become unresponsive or crash.

## 5. **Amplification Attacks**
Amplification attacks exploit the characteristics of certain protocols to increase the volume of traffic directed at a target. A small request from the attacker results in a significantly larger response directed at the victim.

### Examples:
- **DNS Amplification:**
  The attacker sends a small DNS request to a vulnerable DNS server with a spoofed source IP address (the victim's IP). The server responds with a much larger DNS reply, amplifying the attack.

- **NTP Amplification:**
  The attacker sends a small request to an NTP server with a spoofed source IP address (the victim's IP). The server responds with a much larger reply, amplifying the attack.

## 6. **Session Exhaustion Attacks**
In a session exhaustion attack, the attacker tries to exhaust a system's session pool, which can lead to the system being unable to create new sessions for legitimate users.

### Example:
- **Login Flooding:**
  The attacker sends a large number of login requests to a website, causing the server to create numerous sessions or connections, eventually exhausting the server’s resources.

## 7. **Protocol Exploitation**
This type of DoS attack takes advantage of weaknesses or bugs in the protocol or software being used. Attackers can send malformed or malicious packets to exploit vulnerabilities in the communication protocol.

### Example:
- **TCP Connection Exploitation:**
  The attacker sends malformed TCP packets or a large number of half-open connections to the target, causing the server to consume excessive resources and prevent new legitimate connections from being established.

## 8. **Logic Bombs**
A logic bomb is a type of attack that involves malicious code being triggered under specific conditions. It can be used to trigger a denial of service at a certain time or after a particular action is performed.

### Example:
- **Time-based Logic Bomb:**
  An attacker installs malicious code that triggers a DoS condition at a specific time, causing a service to become unavailable when the condition is met.

## Conclusion

DoS attacks vary in their methods and targets but share the goal of rendering a system or network unavailable to legitimate users. Understanding the different types of DoS attacks and how they function is key to developing effective strategies for mitigating their impact. By employing preventive measures such as traffic filtering, rate limiting, and DDoS protection services, organizations can reduce the risk of falling victim to these attacks and ensure the availability of their services.
