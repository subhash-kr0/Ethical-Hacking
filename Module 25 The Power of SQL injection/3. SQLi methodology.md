# SQL Injection (SQLi) Methodology

SQL Injection (SQLi) is a code injection technique that exploits vulnerabilities in an application's database layer by inserting malicious SQL queries. This methodology can help understand how attackers execute SQLi and how to secure applications against such attacks.

---

## 1. **Understanding SQL Injection**
SQL Injection occurs when user input is improperly sanitized, allowing an attacker to execute arbitrary SQL commands on the database. These commands can result in unauthorized data access, modification, or even deletion.

---

## 2. **Types of SQL Injection**
1. **Classic SQL Injection:**
   - Exploiting basic query manipulation to access unauthorized data.
   
2. **Blind SQL Injection:**
   - Exploiting applications that don’t display error messages but behave differently based on input.

3. **Error-Based SQL Injection:**
   - Leveraging error messages returned by the database to gather information.

4. **Union-Based SQL Injection:**
   - Using the `UNION` operator to combine results from multiple queries.

5. **Time-Based Blind SQL Injection:**
   - Inferring information by measuring the time taken for the server to respond.

6. **Out-of-Band SQL Injection:**
   - Utilizing external channels (e.g., DNS or HTTP requests) to exfiltrate data.

---

## 3. **Steps in SQL Injection Methodology**

### Step 1: **Reconnaissance**
- Identify potential injection points such as:
  - Login forms.
  - Search bars.
  - Query strings in URLs.
  - Hidden form fields.

### Step 2: **Identify Entry Points**
- Test inputs using special characters or payloads like:
  ```sql
  ' OR '1'='1'; --
  " OR "1"="1"; --
  ```
- Check for error messages or anomalies.

### Step 3: **Determine Database Information**
- Use payloads to gather information about the database type and structure.
- Example query to identify database:
  ```sql
  ' AND 1=CONVERT(int, @@version); --
  ```

### Step 4: **Extract Data**
- Use SQL commands to retrieve sensitive information such as:
  ```sql
  UNION SELECT username, password FROM users; --
  ```

### Step 5: **Exploitation**
- Modify or delete data.
- Gain administrative access.
- Perform privilege escalation if possible.

---

## 4. **Common SQLi Payloads**
- Login Bypass:
  ```sql
  ' OR '1'='1'; --
  ```
- Data Extraction:
  ```sql
  UNION SELECT column1, column2 FROM table_name; --
  ```
- Blind SQLi Timing Attack:
  ```sql
  ' OR IF(1=1, SLEEP(5), 0); --
  ```

---

## 5. **Preventing SQL Injection**
1. **Input Validation:**
   - Sanitize and validate user inputs.
2. **Parameterized Queries (Prepared Statements):**
   - Use placeholders instead of directly embedding user inputs in queries.
   ```python
   cursor.execute("SELECT * FROM users WHERE username = ? AND password = ?", (username, password))
   ```
3. **Escaping Inputs:**
   - Use proper escaping techniques for special characters.
4. **Least Privilege Principle:**
   - Restrict database user privileges.
5. **Web Application Firewalls (WAFs):**
   - Deploy WAFs to detect and block malicious payloads.
6. **Monitoring and Logging:**
   - Regularly monitor logs for suspicious activities.
