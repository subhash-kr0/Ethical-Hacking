# Learning Basic Python Programming

Python is an excellent language for beginners because of its simple syntax and versatility. This guide covers the basics to get you started on your Python programming journey.

---

## 1. **What is Python?**
Python is a high-level, interpreted programming language designed for readability and simplicity. It is widely used in web development, data analysis, artificial intelligence, and more.

---

## 2. **Setting Up Python**
1. **Download Python**:
   - Visit [python.org](https://www.python.org/) to download and install Python.
   - During installation, check "Add Python to PATH."

2. **Install an IDE or Code Editor**:
   - **VS Code**: Lightweight and beginner-friendly.
   - **PyCharm**: Full-featured Python IDE.
   - **Jupyter Notebook**: Ideal for interactive learning.

3. **Verify Installation**:
   Run this command in the terminal:
   ```bash
   python --version
   ```

---

## 3. **Writing Your First Python Program**
Create a new file with a `.py` extension and add:
```python
print("Hello, World!")
```
Run it in the terminal:
```bash
python your_file_name.py
```

---

## 4. **Basic Syntax and Concepts**

### 4.1 **Variables and Data Types**
Python is dynamically typed, so you don't need to specify data types.
```python
# Variables
name = "Alice"       # String
age = 25             # Integer
height = 5.6         # Float
is_student = True    # Boolean

# Check data types
print(type(name))     # Output: <class 'str'>
print(type(age))      # Output: <class 'int'>
```

---

### 4.2 **Input and Output**
```python
# Input
name = input("Enter your name: ")
print(f"Hello, {name}!")  # Output: Hello, <name>!
```

---

### 4.3 **Control Flow**
#### If-Else Statements
```python
age = 18
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")
```

#### Loops
- **For Loop**
```python
for i in range(5):
    print(i)  # Outputs: 0, 1, 2, 3, 4
```
- **While Loop**
```python
count = 0
while count < 5:
    print(count)
    count += 1
```

---

### 4.4 **Functions**
```python
# Defining a function
def greet(name):
    return f"Hello, {name}!"

# Calling a function
print(greet("Alice"))  # Output: Hello, Alice!
```

---

### 4.5 **Lists and Dictionaries**
- **Lists**
```python
fruits = ["apple", "banana", "cherry"]
print(fruits[0])  # Output: apple
```

- **Dictionaries**
```python
person = {"name": "Alice", "age": 25}
print(person["name"])  # Output: Alice
```
