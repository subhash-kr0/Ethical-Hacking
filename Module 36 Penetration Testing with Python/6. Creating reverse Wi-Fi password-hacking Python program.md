# Creating Reverse Wi-Fi Password-Hacking Python Program

A reverse Wi-Fi password-hacking program extracts saved Wi-Fi passwords from a system. This guide demonstrates how to create such a program in Python for educational and ethical purposes only. Misuse of this information is illegal.

## Prerequisites

1. **Python Installed**: Ensure Python 3.x is installed on your machine.
2. **Administrator Privileges**: Required to access saved Wi-Fi credentials.
3. **Platform**: The script provided works for Windows systems.

---

## Code: Wi-Fi Password Extractor

```python
import subprocess

def get_saved_wifi_passwords():
    try:
        # Fetch Wi-Fi profiles using netsh
        profiles_data = subprocess.check_output("netsh wlan show profiles", shell=True).decode("utf-8", errors="ignore")
        profiles = [line.split(":")[1].strip() for line in profiles_data.split("\n") if "All User Profile" in line]

        wifi_details = []

        for profile in profiles:
            # Fetch password details for each profile
            profile_info = subprocess.check_output(f"netsh wlan show profile "{profile}" key=clear", shell=True).decode("utf-8", errors="ignore")
            password_line = [line.split(":")[1].strip() for line in profile_info.split("\n") if "Key Content" in line]
            password = password_line[0] if password_line else "N/A"
            wifi_details.append({"SSID": profile, "Password": password})

        return wifi_details

    except Exception as e:
        print(f"Error: {e}")
        return []

if __name__ == "__main__":
    print("Fetching saved Wi-Fi passwords...\n")
    wifi_passwords = get_saved_wifi_passwords()

    for wifi in wifi_passwords:
        print(f"SSID: {wifi['SSID']}, Password: {wifi['Password']}")
```

---

## Explanation of the Code

1. **Fetching Wi-Fi Profiles**:
   - The `netsh wlan show profiles` command retrieves all saved Wi-Fi profiles on the system.

2. **Extracting Passwords**:
   - For each profile, `netsh wlan show profile "<SSID>" key=clear` extracts the password if available.

3. **Error Handling**:
   - The script handles exceptions gracefully to avoid crashes.

4. **Output**:
   - Displays a list of SSIDs and their corresponding passwords.
