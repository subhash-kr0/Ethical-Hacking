# Writing Cool Scripts

Scripts are powerful tools for automating tasks, managing systems, and enhancing workflows. In this guide, we'll explore how to write engaging and practical scripts that solve real-world problems.

---

## Characteristics of Cool Scripts

1. **Functional**: Solves a specific problem or automates a task.
2. **Efficient**: Uses resources optimally and runs quickly.
3. **User-Friendly**: Easy to use with clear inputs and outputs.
4. **Customizable**: Flexible to adapt to different needs.
5. **Well-Documented**: Includes comments and instructions for ease of understanding.

---

## Steps to Create a Cool Script

1. **Identify a Problem**:
   - Choose a task or process that could benefit from automation.

2. **Plan Your Script**:
   - Outline the steps or logic needed to achieve the goal.

3. **Select the Right Tools**:
   - Choose a scripting language (e.g., Bash, Python, or PowerShell).

4. **Write the Code**:
   - Begin with a clear structure and include comments for clarity.

5. **Test Thoroughly**:
   - Run the script multiple times to catch and fix errors.

6. **Add Enhancements**:
   - Include additional features, user inputs, or error handling.

---

## Example: Disk Usage Analyzer Script (Bash)

```bash
#!/bin/bash
# Disk Usage Analyzer

echo "Analyzing disk usage..."

df -h | awk 'NR==1 || $5+0 > 80 { print $0 }' > disk_report.txt

if [ -s disk_report.txt ]; then
    echo "High disk usage detected. See disk_report.txt for details."
else
    echo "Disk usage is under control."
    rm disk_report.txt
fi
```

## Example: To-Do List Manager (Python)

```python
# To-Do List Manager

def display_menu():
    print("\nTo-Do List Manager")
    print("1. View Tasks")
    print("2. Add Task")
    print("3. Remove Task")
    print("4. Exit")

def main():
    tasks = []
    while True:
        display_menu()
        choice = input("Choose an option: ")

        if choice == "1":
            if tasks:
                print("\nYour Tasks:")
                for i, task in enumerate(tasks, 1):
                    print(f"{i}. {task}")
            else:
                print("\nNo tasks found.")

        elif choice == "2":
            task = input("Enter a new task: ")
            tasks.append(task)
            print(f"\nTask added: {task}")

        elif choice == "3":
            if tasks:
                for i, task in enumerate(tasks, 1):
                    print(f"{i}. {task}")
                idx = int(input("Enter the task number to remove: "))
                if 0 < idx <= len(tasks):
                    removed = tasks.pop(idx - 1)
                    print(f"\nTask removed: {removed}")
                else:
                    print("\nInvalid task number.")
            else:
                print("\nNo tasks to remove.")

        elif choice == "4":
            print("Exiting To-Do List Manager. Goodbye!")
            break

        else:
            print("\nInvalid option. Try again.")

if __name__ == "__main__":
    main()
```

## Tips for Writing Cool Scripts

1. **Keep It Simple**: Focus on functionality and ease of use.
2. **Use Modular Code**: Break your script into functions for better readability and reusability.
3. **Incorporate Error Handling**: Prevent unexpected crashes by handling errors gracefully.
4. **Add Interactivity**: Allow user inputs for a dynamic experience.
5. **Optimize Performance**: Avoid redundant computations and optimize resource usage.
