# Learning Basic Shell Scripting

Shell scripting is an essential skill for automating tasks and managing systems efficiently. This guide introduces basic shell scripting concepts and commands to help beginners get started.

---

## What is Shell Scripting?

Shell scripting involves writing a sequence of commands in a script file to be executed by a shell interpreter. These scripts simplify repetitive tasks, enable automation, and enhance system functionality.

---

## Advantages of Shell Scripting

1. **Automation**: Save time by automating repetitive tasks.
2. **Efficiency**: Perform complex tasks with a single script.
3. **Flexibility**: Combine commands to create custom workflows.
4. **Integration**: Easily integrate with other programs and tools.

---

## Basic Components of Shell Scripting

1. **Shebang (`#!`)**:
   - Indicates the script interpreter (e.g., Bash).
   - Example:
     ```bash
     #!/bin/bash
     ```

2. **Comments**:
   - Use `#` to add comments for clarity.
   - Example:
     ```bash
     # This is a comment
     ```

3. **Variables**:
   - Store data for reuse.
   - Example:
     ```bash
     name="John"
     echo "Hello, $name!"
     ```

4. **Input and Output**:
   - Read user input and display output.
   - Example:
     ```bash
     echo "Enter your name:"
     read name
     echo "Welcome, $name!"
     ```

5. **Control Structures**:
   - Conditional statements and loops to control script flow.
   - Example:
     ```bash
     if [ "$name" == "Admin" ]; then
         echo "Welcome, Admin!"
     else
         echo "Access denied."
     fi
     ```

---

## Steps to Write and Execute a Shell Script

1. **Create a Script File**:
   - Use a text editor to write the script.
   - Example:
     ```bash
     #!/bin/bash
     echo "Hello, World!"
     ```

2. **Save the File**:
   - Save the script with a `.sh` extension (e.g., `script.sh`).

3. **Make the Script Executable**:
   - Use `chmod` to grant execute permissions:
     ```bash
     chmod +x script.sh
     ```

4. **Run the Script**:
   - Execute the script:
     ```bash
     ./script.sh
     ```

## Example: Simple Calculator Script

```bash
#!/bin/bash
# Basic Calculator

echo "Enter first number:"
read num1
echo "Enter second number:"
read num2
echo "Enter operation (+, -, *, /):"
read op

if [ "$op" == "+" ]; then
    echo "Result: $((num1 + num2))"
elif [ "$op" == "-" ]; then
    echo "Result: $((num1 - num2))"
elif [ "$op" == "*" ]; then
    echo "Result: $((num1 * num2))"
elif [ "$op" == "/" ]; then
    echo "Result: $((num1 / num2))"
else
    echo "Invalid operation."
fi
```

## Tips for Beginners

1. **Start Simple**: Begin with basic commands and gradually incorporate advanced features.
2. **Practice Regularly**: Write scripts for daily tasks to build confidence.
3. **Debugging**: Use `set -x` for debugging your scripts.
4. **Use Online Resources**: Refer to tutorials and documentation for guidance.

## Additional Commands to Learn

- **`echo`**: Display messages or variables.
- **`read`**: Take user input.
- **`if`/`elif`/`else`**: Conditional execution.
- **`for`/`while`**: Loops for iteration.
- **`case`**: Multi-way branching.
- **`functions`**: Reusable code blocks.
